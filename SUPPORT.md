# Support

Before filing an issue, read the [installation guide](docs/installation.md), restart Zotero, and rerun the installer for your platform.

For bug reports, include:

- Paper Chat for Zotero version;
- Zotero version and UI language;
- operating system, architecture, and Python versions;
- exact steps to reproduce;
- expected and actual behavior;
- a screenshot when the problem is visual;
- relevant lines from `%LOCALAPPDATA%\PaperChatForZotero\bridge.log` on Windows or `~/Library/Application Support/PaperChatForZotero/bridge.log` on macOS, plus Zotero debug output.

Remove paper text, file paths, account details, tokens, and other personal information before posting logs. Never upload `token.txt`, Codex authentication files, or a private paper unless you have permission.

Use GitHub Issues for reproducible bugs and feature requests. Security vulnerabilities must follow [SECURITY.md](SECURITY.md).
