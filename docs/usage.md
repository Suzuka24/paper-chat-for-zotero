# 使用指南

## 开始论文对话

1. 在 Zotero 中打开一篇已经下载到本地的 PDF。
2. 点击右侧导航中的 Paper Chat 图标。
3. 选择模型和推理强度，然后输入问题。
4. 使用“新对话”为当前论文创建独立线程；第二行可以切换、重命名或删除历史对话。

新对话开始时，插件会在本地解析当前 PDF 并提供给 Codex。没有文本层的扫描版 PDF 可能需要先执行 OCR。

## 添加上下文

- 选中 PDF 文字后点击“询问 Codex”。
- 从标注右键菜单添加高亮、区域或墨迹标注。
- 从“添加条目笔记作为上下文”中选择一个或多个笔记；笔记变化后点击“刷新”。
- 点击“附件”选择本地文件。
- 在输入框直接粘贴剪贴板图片、PDF、Office 文档、文本文件，或 Windows 资源管理器中复制的文件。

除当前论文外，只有用户明确选择或添加的内容才会加入上下文。

## 使用回答

- 侧栏支持 Markdown、表格、代码块、行内公式和行间公式。
- “第 3 页”等页码引用可以点击并跳转到 PDF 物理页。
- 每条消息下方的图标可复制该消息，或保存到选定的 Zotero 笔记。
- “备份笔记”可将完整对话保存到新建或指定条目笔记。
- 拖动输入框上方的横向手柄可调整对话历史区域高度。

## 通用设置

打开 `编辑 → 设置 → Paper Chat for Zotero`，可以设置默认回答语言、回答风格和长期通用 Prompt。修改从下一条提问开始生效。

## 登录与桥接服务

插件通过本地桥接启动独立的官方 Codex App Server，并复用当前 Windows 用户仍然有效的 Codex 登录；Codex 客户端不需要保持开启。如果账号或模型列表不可用，请重新登录官方 Codex 客户端，或运行 `codex login`。

桥接控制、升级、日志和故障排查见[安装指南](installation.md)。
